## Usage

These rules are automatically applied by Cursor AI when you're working on this project. They help ensure:

- Consistent code quality across the project
- Adherence to best practices for NestJS development
- Proper handling of AI/ML specific requirements
- Security and performance optimization
- Maintainable and scalable codebase

## Customization

You can modify these rules based on your specific requirements. The rules are organized in a hierarchical manner:

1. **General rules** apply to all code
2. **Backend rules** apply to server-side code
3. **Node.js rules** apply to JavaScript/TypeScript code
4. **NestJS rules** apply to framework-specific code
5. **Product rules** apply to AI learning services specific features

## Contributing

When adding new features or modifying existing code, refer to these rules to ensure consistency and quality. Update the rules as needed when new patterns or requirements emerge.
